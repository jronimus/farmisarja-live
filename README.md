# Farmisarja Live

[Siirry sarjataulukkoon](https://jronimus.github.io/farmisarja-live/)

Oman Fantasy Premier League -kaverisarjamme seurantasivu. Sivulta löytyvät sarjataulukko, kierroksen pisteet, otteluseuranta sekä joukkueiden ja pelaajien vertailut.

Tämä repositorio sisältää sivuston julkisen käyttöliittymän ja GitHub Pages -julkaisun tarvitsemat tiedostot. Palvelimen asetukset, Telegram-integraation tiedot ja ylläpidon muistiinpanot säilytetään erillään.

Sivusto on epävirallinen eikä ole Fantasy Premier Leaguen tai Premier Leaguen ylläpitämä.
